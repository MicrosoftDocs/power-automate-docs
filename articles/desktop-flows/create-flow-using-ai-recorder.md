# Record with Copilot for desktop flows (deprecated)

> [!IMPORTANT]
> Record with Copilot (also known as the AI Recorder) is deprecated and is no longer available in Power Automate for desktop.

## Alternatives

To create desktop flows, use one of the following approaches:

- [Describe your flow with natural language using Copilot](copilot-in-power-automate-for-desktop.md#create-a-desktop-flow-using-copilot-preview) and use the [recorder](recording-flow.md) as needed.
- Create an agent in **Copilot Studio** with [computer use](/microsoft-copilot-studio/computer-use), which lets you automate tasks on a computer by simply describing what you want it to do in natural language.
