# Record with Copilot for desktop flows (deprecated)

> [!IMPORTANT]
> Record with Copilot (also known as the AI recorder) is deprecated and isn't available in Power Automate for desktop.

## Alternatives

To create desktop flows, use one of the following approaches:

- [Describe your flow with natural language using Microsoft Copilot](copilot-in-power-automate-for-desktop.md#create-a-desktop-flow-using-copilot-preview) and use the [recorder](recording-flow.md) as needed.
- Create an agent in Microsoft Copilot Studio with [computer use](/microsoft-copilot-studio/computer-use), which lets you automate tasks on a computer by describing what you want it to do in natural language.
